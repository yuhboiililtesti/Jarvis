# JARVIS V3.1 — Security and Execution Reliability

**Status:** In Progress | **Owner:** Topaz | **Last updated:** 2026-11-03

## Goals
1. Isolate remote command execution from privileged host services
2. Separate node permissions by capability rather than shared token only
3. Make every execution path enforce the same authorization policy
4. Add regression tests for privilege boundaries
5. Preserve compatibility with PC-001, APOS, LAPTOP-001
